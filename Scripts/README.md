This directory contains the numerical codes and post-processing routines used in this study.

## Contents

- **Fortran 90 source code**  
  Implementation of the 2D generalized time-dependent Ginzburg–Landau (GTDGL) equations used to simulate vortex dynamics in Pb–Nb core-shell superconductors.

- **MATLAB scripts**  
  Post-processing routines used to:
  - Generate current–voltage (IV) curves
    - Visualize order-parameter (ψ) distributions
  - Produce vortex configuration maps
  - Create figures and videos included in the manuscript

## Notes
These scripts allow reproduction of all figures presented in the manuscript.

# Monostructure Data

This directory contains the raw and processed simulation data for the Pb monostructure configuration.

## Contents

- Order-parameter field data (ψ)
- Current–voltage (IV) datasets

## Data Description

The data were generated using 2D generalized time-dependent Ginzburg–Landau (GTDGL) simulations under applied transport current and external magnetic field.

Each subdirectory corresponds to a specific set of simulation parameters, typically organized by:
- Order-parameter field data (ψ) 
   - transport current
     - Psi file 

These datasets support the results discussed in the manuscript and ensure reproducibility of the reported critical currents and resistive transitions.
